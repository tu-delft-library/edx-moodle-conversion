# PHP API Reference

This page explains the generated PHP reference. The reference itself is produced from PHPDoc blocks in
`moodle-plugin/`.

<a href="../api/php/index.html">Open the PHP API reference</a>

Run the complete build from the repository root:

```bash
composer install --working-dir=tools/phpdoc
./scripts/build-docs.sh
```

Do not edit `docs/api/php/` manually. It is regenerated on every complete documentation build.
